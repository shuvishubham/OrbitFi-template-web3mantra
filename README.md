# 🚀 Getting Started

Follow these steps to clone and run **OrbitFi** on your local machine.

## 1. Clone the Repository

```bash
git clone https://github.com/shuvishubham/OrbitFi-template-web3mantra.git
```

## 2. Navigate to the Project Directory

```bash
cd OrbitFi-template-web3mantra
```

## 3. Install Dependencies

Install all the required Node.js packages:

```bash
npm install
```

## 4. Configure Environment Variables

Create a `.env` file in the root directory of the project.

Add your OpenAI API key:

```env
OPENAI_API_KEY=your_openai_api_key_here
```

**Note:** Replace `your_openai_api_key_here` with your valid OpenAI API key.

You can obtain an API key from the [OpenAI Platform](https://platform.openai.com/api-keys).

**Important:** Never share your API key or commit your `.env` file to GitHub.

## 5. Start the Development Server

Run the following command:

```bash
npm run dev
```

## 6. Open the Application

Once the development server starts, open your browser and visit:

```text
http://localhost:3000
```

🎉 That's it! OrbitFi should now be running on your local machine.
